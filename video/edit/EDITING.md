# Editing the FirstDose demo video

This folder is a [HyperFrames](https://hyperframes.heygen.com) project: the video is HTML + GSAP,
rendered to MP4. Everything on screen is generated by **`build.py`**, so most edits are a
one-line change there followed by `npm run build`.

Current cut: **2:43** (hard cap 3:00). Final render: `../FirstDose-demo.mp4`.

## Setup (once)

1. Install Node 20+, Python 3.10+, ffmpeg, and Git LFS.
2. From the repo root: `git lfs pull` (downloads the face clips, footage and music).
3. In this folder:
   ```bash
   npm install
   npx hyperframes skills update general-video   # installs the HyperFrames skills for Claude Code
   cp AGENTS.md CLAUDE.md                        # CLAUDE.md is gitignored in this repo; Claude Code reads it automatically
   ```

## Edit with Claude Code

Open Claude Code in this folder and describe the change, e.g. *"make the face circles bigger"*,
*"move the 27% card earlier"*, *"change Minh's step 02 title"*. Point it at this file first:

> Read EDITING.md and BRIEF.md, then use /hyperframes to make this change: ...

Rules for Claude (and humans):

- **Edit `build.py`, never the generated `index.html` / `compositions/*.html`** — they are overwritten on every build.
- After any edit: `npm run build` (runs `build.py`, then re-carves the music around the voices),
  then `npx hyperframes check` (must say "Check passed").
- Preview: `npm run dev` (Studio at localhost). Render: `npx hyperframes render -o renders/cut.mp4 -q delivery --video-frame-format png`,
  then normalize loudness:
  `ffmpeg -i renders/cut.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k -movflags +faststart ../FirstDose-demo.mp4`
- Every claim on screen must match `docs/presentation/claims-and-evidence.md` on main. Say "confirmed first fills",
  never "recovered"/"started". Keep the disclosure footers.

## Where things live in `build.py`

| What | Where |
|---|---|
| Scene order + lengths | `SCENES` |
| Names / roles under face circles | `PEOPLE` |
| Face crop (zoom) | `face_circle(..., span=880)` — bigger span = more zoomed out; face centres in `FACE_CENTER` |
| Captions (clean wording, per scene) | `HOOK_CUES`, `PITCH_CUES`, `MARIA_CUES`, `JAMES_CUES`, `MARKET_CUES` — `(start, end, "text")`, `*word*` = blue emphasis |
| Left-panel step titles | `MARIA_STEPS`, `JAMES_STEPS` — `a` = appear time |
| Which app footage plays when | `MARIA_SEGS`, `JAMES_SEGS` — `T` = capture wall-clock (see `capture/out/marks.json`), `focus` = desk / phone / both / wide, `zoom` = (scale, x, y) punch-in |
| Hook, landing page, market, end card | `hook_scene()`, `pitch_scene()`, `market_scene()`, `endcard_scene()` |
| Colours / fonts | top of file (the app's own palette + Geist) |
| Music volume | `index()` → `a-bgm` `data-volume` |

All times inside a scene are **seconds from the start of that scene**.

## Media

| Folder | Contents |
|---|---|
| `assets/faces/` | Face clips (from `../*.mov`), levelled to -16 LUFS. Swap a take by replacing the file with the same name. |
| `assets/voice/` | Audio extracted from the face clips (what you hear). Regenerate after swapping a face clip: `ffmpeg -i assets/faces/X.mp4 -vn -c:a aac -b:a 192k -ar 48000 -ac 2 assets/voice/X.m4a` |
| `assets/footage/` | Live recording of firstdose.vercel.app (desktop 1440×810, phones 390×844 ×2) |
| `assets/music/bed.mp3` | ElevenLabs Music instrumental bed |
| `transcripts/` | Word-level timings (faster-whisper) used to time captions |

A re-recorded face clip changes its timing: re-run `python transcripts/run.py` and adjust that scene's cues and duration.

## Re-recording the live footage (rarely needed)

`capture/record_live.py` drives production with Playwright. **It resets the shared live run, seeds it,
runs Maria + James, then resets to zero** — get the team's OK first. Needs `FIRSTDOSE_DEMO_TOKEN` set.
